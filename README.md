# 📖 קוֹל הָרַבִּים — ManyVoices (MV)

**סידור תפילה נגיש, מנוקד, בעריכה פתוחה — בלשון המסורת ובקול הרבים.**

**מטרות:** תפילה עם פירוש מילים קשות; עזרה למתקשים בקריאה; שמירה על הבחנה בין נוסח מסורתי לבין חיבורים מקוריים; תפילה גם למען מי שקולם אינו נשמע.

## 🏠 התחלה
1. חלצו את קובץ ה־ZIP לתיקייה.
2. פתחו את `index.html` בדפדפן. האתר פועל ללא התקנה וללא ספריות צד שלישי.
3. ניתן לדפדף בתפילות ולחפש במילים, להגדיל אותיות ולבחור תצוגת הסבר.
4. עריכת תפילה: `prayers/traditional/` או `prayers/original/`; עדכנו גם את `prayers/index.json` ואת `prayers-data.js` באמצעות `python3 tools/build_catalog.py`.
5. לפריסה דרך GitHub Pages: הפעילו Pages על שורש ענף `main`.

## 📁 מבנה המאגר
- `prayers/traditional/` — נוסחים מסורתיים קצרים מוכרים שהובאו כאן במלואם, בהתאם לסיווגם. לפני פרסום נוסח מחייב יש לערוך בדיקת הגהה ונוסח לפי מנהג.
- `prayers/original/` — תפילות חדשות מנוקדות; אינן ברכות חז״ל ואינן תחליף לחיוב הלכתי.
- `prayers/drafts/` — מפת פיתוח לתפילות המסורתיות הארוכות שטרם נכללו.
- `prayers/index.json` — קטלוג קריא למכונה; `prayers-data.js` נוצר אוטומטית ממנו ומקובצי Markdown.
- `docs/` — הסברים, קו עריכתי, רשימת שערים, נגישות ו־API.
- `.github/` — תבניות דיווח, PR ופעולות אוטומציה.
