# תפילות מסורתיות להשלמה
אין להוסיף קובץ כאילו הוא נוסח מלא אם יש בו השמטות. בכל שלב להוסיף נוסח מדויק, מסורת מוגדרת, סימוכין ובדיקת הגהה.

- [ ] נטילת ידיים וברכות השחר בשלמותן
- [ ] אשר יצר, ברכות התורה והקורבנות
- [ ] ברוך שאמר, פסוקי דזמרה, ישתבח
- [ ] יוצר אור, אהבה רבה/אהבת עולם וקריאת שמע בשלוש פרשיותיה
- [ ] אמת ויציב, תפילת עמידה שחרית, תחנון, עלינו
- [ ] מנחה וערבית בשלמותן
- [ ] קריאת שמע שעל המיטה
- [ ] שבת: קבלת שבת, עמידות, קידוש, מוסף, הבדלה
- [ ] ברכת המזון, ברכות הנהנין
- [ ] מועדים לפי נוסח ומנהג
