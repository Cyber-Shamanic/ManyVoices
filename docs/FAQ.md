# ❓ שאלות נפוצות
**האם זה סידור מלא?** עדיין לא. גרסה 0.1.0 היא שלד פעיל עם תפילות קצרות ומקוריות; פרקי תפילה ארוכים מתוכננים בהמשך.

**האם תפילות "קול הרבים" הן נוסח חז״ל?** לא. הן חיבורים חדשים ומסומנות כך.

**מה משמעות הניקוד?** סימני תנועה שמסייעים לקרוא ולהגות מילים.

**איך מתמודדים עם מילים קשות?** לכל תפילה מצורף פירוש נגיש או תיאור כוונה; בהמשך יוסף מילון מפורט.

**אפשר לקרוא בלי חיבור לרשת?** כן, לאחר הורדת המאגר ופתיחת `index.html`.

**איך מוסיפים תפילה?** פותחים קובץ Markdown, מוסיפים לקטלוג ומריצים `tools/build_catalog.py`.

**איך מדווחים על טעות?** דרך Issue או מייל בהתאם ל־`SUPPORT.md`.
