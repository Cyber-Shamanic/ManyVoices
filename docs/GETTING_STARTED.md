# 🚀 התחלה מהירה
## קריאה
פתחו `index.html` בדפדפן; בחרו תפילה מסרגל הניווט, השתמשו בתיבת החיפוש, לחצו +/− לגודל כתב, והפעילו "הצג פירוש".

## פיתוח
נדרש Python 3 רגיל רק ליצירת קטלוג חדש: `python3 tools/build_catalog.py`. פתחו קובץ Markdown ב־`prayers/original/`, כתבו כותרת, תיאור, טקסט ופירוש; הוסיפו רשומה ל־`prayers/index.json`; הפעילו את הכלי לרענון `prayers-data.js`.

## פרסום
העלו ל־GitHub כמאגר סטטי והפעילו Pages מתיקיית השורש. האתר אינו מחייב npm או שירות חיצוני.
